# Tiny Tenants

A cozy house-building and life game that runs in the browser. Build a home square by square, then watch your tiny tenants move in, live their lives and make a mess of it.

- **Build:** walls, doors, windows, floors, stairs, upper floors, roofs (flat or gable), fences, and pools and spas of any shape.
- **Furnish:** beds, sofas, kitchens, bathrooms, lamps, decor and pets. Right-click a palette item to pick its color, and hold-drag while placing to turn it.
- **Live:** pawns with needs who sleep, eat, cook, wash, chat, swim, dive and soak. Right-click the ground or a piece to tell them what to do.

## Running it

```bash
npm install
npm run dev
```

Then open the address Vite prints (usually http://localhost:5173/). Your houses save in the browser's local storage.

## Other scripts

- `npm run build`: type-checks and builds the site into `dist/`.
- `npm run build:artifact`: builds a single self-contained HTML page into `dist-artifact/`.
